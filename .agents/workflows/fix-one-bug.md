# Fix One Bug

Solve exactly one bug.

1. Identify the affected flow.
2. Read relevant files.
3. Reproduce or prove the issue.
4. Explain root cause.
5. Propose the minimum fix.
6. Modify only necessary files.
7. Run syntax/lint validation.
8. Run targeted local test.
9. Verify observable result.
10. Report PASS / FAIL.
11. Clean temporary test files.

If another bug is discovered:
report it but do not fix it.

Never expand scope automatically.
